# Selected model record

This document describes the model behind the current application. Superseded development notes are preserved privately in the cleanup backup.

## Selected artifact

- Identity: `harvestguard-v3-candidate-1`.
- Selection: trial 6, ML weight 1, historical-prior alpha 0.
- Saved artifact: `model_v3_candidate/model_v3_candidate.joblib`.
- SHA256: `6969c3c60a10571fd5e7644173f01568f9f496d64000beacb0fa0b7fee71eb64`.
- Original source and environment: the module and requirements file inside `model_v3_candidate/`.
- Model: occurrence classifier times positive-loss Gamma severity model, using XGBoost.
- Target: storage, processing and packaging loss as a percentage of production.
- Inputs: season, district, crop, farmer type, harvest month, plot count, crop plot area, crops in plot, preceding 30-day rainfall and preceding seven-day humidity.

The root module adds inference and quantity utilities. The development notebook and aggregation notebook embed that root source. The bundle's original module is retained for loading the saved model classes. See [bundle explanation](model_v3_candidate/README.md).

## Current application outputs

`model_v3_quantity_results/` contains the inference-only quantity export from 50,475 eligible 2025 profiles into 944 groups. Each profile's rate is converted to kg before group aggregation. `quantity_aggregation_metadata.json` records the private input hash and the unchanged model hash. `real_data_aggregation_checks.json` records the completed arithmetic and group checks.

`model_v3_insights/` contains the matched aggregate explanation evidence and predictive importance generated by `harvestguard_insights_export.py`. Local sensitivities are model comparisons; they are not causal effects or benefits from interventions.

The rate-only CSV inside the model bundle is original evaluation evidence. The map uses the production-weighted kg priorities. Quantities cover the scored sample, not national totals, and no new kg-ranking validation or treatment-effect estimate is claimed.

## Remaining reproduction gaps

The cleaning and model-building code are present. The original 2025 raw-module pre-merge implementation and exact production-bearing dataset construction are not present. The supplied private CSVs differ by ten rows overall. [Project audit](PROJECT_AUDIT.md) records what must be recovered; this cleanup does not invent a historical pipeline or retrain the selected model.
